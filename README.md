# Nhywyll – website

Source code of [nhywyll.com](https://nhywyll.com), the personal website of the VTuber and streamer Nhywyll.

This is a personal website, not a template. The code is open so people can see how it is built.

## What it has

- Five pages: Home, Links, Contact, Credits, Imprint/Privacy
- English and German
- Light theme ("sky") and dark theme ("sea")
- Latest YouTube Shorts, fetched at build time, so visitors never contact YouTube
- Live/schedule button for Twitch
- Cookie banner; analytics only after consent
- Small effects: falling feathers, bird tracks on click, a hidden chick. All off with "reduce motion".

## Built with

HTML, CSS and TypeScript, bundled with [Vite](https://vite.dev). No framework. Hosted on GitHub Pages.

Setup, commands and deployment: [DEVELOPMENT.md](./DEVELOPMENT.md)
